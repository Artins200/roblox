# ✦ Arena Agent — ИИ-агент прямо в Roblox Studio

Плагин для Roblox Studio, который превращает **arena.ai**-стиль агентного режима в
внутриигровой инструмент: вы пишете задачу в чат — агент **сам генерирует скрипты,
объекты и свойства прямо в открытом месте (place)**. Не «вот вам код, вставьте
руками», а буквально: ИИ-агент живёт в Studio и строит игру за вас.

```
┌─────────────────────┐   HTTPS    ┌──────────────────────────────┐
│  Roblox Studio      │ ────────►  │  LLM-провайдер               │
│  плагин ArenaAgent  │ ◄────────  │  OpenRouter / OpenAI /       │
│                     │   JSON     │  Anthropic / Ollama / bridge │
│  чат + исполнитель  │            └──────────────────────────────┘
│  ops над DataModel  │                    ▲
└─────────────────────┘                    │ (опционально)
                                    ┌──────┴───────┐
                                    │ bridge       │  ключи хранятся
                                    │ server.mjs   │  локально, Node 18+
                                    └──────────────┘
```

Плагин — **один файл** `plugin/ArenaAgent.lua`, без внешних зависимостей.

## Быстрый старт (5 минут)

### 1. Установите плагин

Положите файл в папку плагинов Studio — **точно ту, которую открывает сама Studio**:
вкладка **Plugins → кнопка «Plugins Folder»** (откроется нужная директория):

- Windows: `%LOCALAPPDATA%\Roblox\Plugins\`
- macOS: `~/Documents/Roblox/Plugins/`

Два равнозначных варианта файла:

| Вариант | Файл | Когда выбирать |
|---|---|---|
| **A. Скрипт** | `plugin/ArenaAgent.lua` | обычный путь |
| **B. Модель** | `plugin/ArenaAgent.rbxmx` | запасной: не зависит от кодировки/скрытых расширений Windows |

> ⚠️ Файл должен называться именно `ArenaAgent.lua` (или `.rbxmx`). Windows по
> умолчанию скрывает расширения — проверьте, что не получился `ArenaAgent.lua.txt`.

### 2. Полностью перезапустите Studio

Плагины читаются **только при старте Studio**. Закройте все окна Studio и откройте заново.

### 3. Проверьте Output и найдите кнопку

Откройте окно **Output** (вкладка **View → Output**). При старте там должны быть строки:

```
[ArenaAgent] v1.0.1: загрузка…
[ArenaAgent] v1.0.1: готов. Кнопка — вкладка Plugins, секция «Arena AI» → «Arena Agent».
```

Кнопка **«Arena Agent»** — на вкладке **Plugins** в секции **«Arena AI»** (в новой
ленте Studio секция может быть справа — прокрутите/разверните ленту).

### 4. Вставьте ключ и опишите задачу

⚙ в плагине → провайдер (проще всего [OpenRouter](https://openrouter.ai/keys), есть
бесплатные модели; Ollama/LM Studio — совсем без ключа) → откройте любой place и
напишите в чат:

> «Сделай систему двойного прыжка: LocalScript в StarterPlayerScripts + настрой Humanoid»

Агент ответит планом и **сразу создаст скрипты и объекты в вашем place**.
Не понравилось — `Ctrl+Z` (все правки агента — один undo-шаг).

### Если плагин не появился — по строкам в Output

| Что в Output | Что это значит |
|---|---|
| `…готов. Кнопка — вкладка Plugins…` | Плагин загружен. Ищите секцию «Arena AI» на вкладке Plugins (ленту можно прокручивать). |
| `…ОШИБКА ИНИЦИАЛИЗАЦИИ → …` | Плагин загрузился, но упал при старте — **кнопка всё равно есть**, а текст после стрелки скажет причину (пришлите его в issue). |
| Строк `[ArenaAgent]` нет вообще | Studio не видит файл. Проверьте: 1) точная папка из шага 1 (не подпапка с версиями); 2) расширение не `.txt`; 3) файл не пустой; 4) попробуйте вариант B (`.rbxmx`). |
| `…Это плагин Roblox Studio: положите файл…` | Скрипт запущен не как плагин (например, выполнен в командной строке Studio или внутри игры). Положите его в папку Plugins. |

## Провайдеры

| Пресет в ⚙ | Endpoint | Ключ | Модель по умолчанию |
|---|---|---|---|
| OpenRouter | `https://openrouter.ai/api/v1` | [openrouter.ai/keys](https://openrouter.ai/keys) | `anthropic/claude-sonnet-4.5` |
| OpenAI | `https://api.openai.com/v1` | [platform.openai.com](https://platform.openai.com/api-keys) | `gpt-4.1-mini` |
| Anthropic | `https://api.anthropic.com/v1` | [console.anthropic.com](https://console.anthropic.com/) | `claude-sonnet-4-5` |
| Ollama (локально) | `http://localhost:11434/v1` | не нужен | `qwen2.5-coder:7b` |
| LM Studio (локально) | `http://localhost:1234/v1` | не нужен | любая загруженная |
| Arena bridge | `http://localhost:8787` | ключ в bridge | берётся из bridge |
| Arena.ai (beta) | `https://api.arena.ai/v1` | — | — |

> **Про arena.ai.** Публичного API агентного режима arena.ai пока нет, поэтому пресет
> «Arena.ai (beta)» — это готовый слот: OpenAI-совместимый формат + редактируемый URL.
> Когда у платформы появится эндпоинт, достаточно вписать его в ⚙ или в bridge —
> и плагин заработает с arena.ai без переделок.

### Bridge (опционально)

Локальный мост `bridge/server.mjs` (Node ≥ 18, **ноль зависимостей**):

- ключи не хранятся в Studio — только в `config.json`/env на вашем компе;
- провайдер меняется одной строкой, Studio вообще не трогаем.

```bash
cd arena_agent/bridge
cp config.example.json config.json   # вписать ключ и провайдера
node server.mjs

# проверка без Studio (поднимет фейковый провайдер):
node mock-server.mjs                 # терминал 1
ARENA_BRIDGE_PROVIDER=openai ARENA_BRIDGE_ENDPOINT=http://localhost:9999/v1 \
  ARENA_BRIDGE_MODEL=mock-model node server.mjs   # терминал 2
node test-client.mjs                 # терминал 3 — увидите reply/ops/done
```

В Studio: провайдер **«Arena bridge»**, endpoint `http://localhost:8787` (порт из конфига).

## Что умеет агент

Работает циклом: модель присылает JSON-план `{reply, ops, done}` → плагин применяет
`ops` к DataModel → отчёт об ошибках уходит модели → она продолжает (`done=false`),
пока не закончит (`done=true`). Ошибки (несуществующий путь, плохой энум, занятый
путь) агент видит и чинит сам, без вашего участия.

| Операция | Что делает |
|---|---|
| `upsert_script` | создать/обновить `Script`/`LocalScript`/`ModuleScript` (создаст папки-предки) |
| `create_instance` | создать экземпляр любого класса, с `properties` и рекурсивными `children` (+`replace`) |
| `set_properties` | проставить свойства существующему объекту |
| `set_attribute` | атрибут объекта |
| `delete_instance` / `rename_instance` / `move_instance` | удалить / переименовать / переместить |
| `get_source` | прочитать код скрипта (агент сам вызывает перед правками) |
| `get_properties` / `list_children` | прочитать состояние мира |

Форматы значений (всё понимается автоматически, с учётом типа свойства):

```
"Size":[4,1,2]                                   # короткий массив
"Size":{"__t":"Vector3","v":[4,1,2]}             # явный тип
"Material":"Material.Neon"                       # энум строкой
"Color":{"__t":"Color3","hex":"FF8800"}          # цвет из hex
"Color":{"__t":"Color3","v":[255,128,0]}         # 0..255 → fromRGB
"CFrame":{"__t":"CFrame","v":[10,5,0]}           # позиция
"Door":{"__t":"Instance","v":"Workspace/Door"}   # ссылка на объект
```

Плюс в каждом запросе агент видит:

- **снимок места** — дерево Workspace, ReplicatedStorage, ServerScriptService,
  StarterGui, StarterPlayer и т.д. (глубина/размер ограничены);
- **выделение в Studio** вместе с исходниками выделенных скриптов.

| Кнопка | Действие |
|---|---|
| ✨ Объяснить | объясняет выделенное (объекты + код) |
| 🛠 Починить | ищет баги в выделенных скриптах и исправляет |

## Безопасность и откат

- Все правки за ход агента — **один waypoint в ChangeHistoryService**: `Ctrl+Z` откатывает.
- Лимиты: ≤150 ops за ход, ≤800 экземпляров, ≤200k символов на скрипт, ≤12 авто-итераций.
- Ключ хранится через `plugin:SetSetting` (локально в Studio) и уходит только на выбранный
  провайдер. С bridge — вообще не вводится в Studio.
- Плагин пишет только в открытый place. Системные сервисы, чужие скрипты без явной
  просьбы — не трогает (правило зашито в системный промпт).
- Перед большой сессией сохранитесь / используйте систему контроля версий
  (`*.rbxlx` — текстовый формат, удобно для git, как в этом репозитории).

```

├── README.md              ← вы здесь
├── plugin/
│   ├── ArenaAgent.lua     ← сам плагин (один файл, Luau)

└── tests/
    ├── fake_roblox.lua    ← заглушка Roblox API
```

### Тесты

Логика плагина (парсер JSON-ответов, применение ops, преобразования значений,
сборка контекста, полный цикл агента с фейковым HTTP) гоняется вне Studio:

```bash
pip install lupa
python3 arena_agent/tests/run_tests.py   # Итог: 63 прошло, 0 упало
```

## Траблшутинг

| Симптом | Причина / решение |
|---|---|
| Плагина нет в меню, в Output пусто | Studio не видит файл — см. таблицу «Если плагин не появился» выше (папка, расширение `.lua.txt`, перезапуск, вариант B) |
| В Output «ОШИБКА ИНИЦИАЛИЗАЦИИ» | кнопка есть, причина — в тексте ошибки в Output |
| «Ошибка запроса: … 401» | неверный ключ — проверьте в ⚙ |
| «… 404» | опечатка в endpoint или названии модели |
| «… 429» | лимит/баланс провайдера |
| «Модель вернула не-JSON» | возьмите модель помощнее (sonnet/gpt-class); плагин сам делает ретрай |
| Ollama недоступна | `ollama serve` + `ollama pull qwen2.5-coder:7b` |
| Нужен полный провайдер без ключа в Studio | поднимите bridge |
