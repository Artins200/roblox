# EPIC COMBAT ARENA — эпичная система боёвки для Roblox Studio

Один файл — готовая боевая арена. Открой **`epic_combat.rbxlx`** в Roblox Studio
(File → Open from File…), нажми **Play (F5)** и устрой тотальную облитерацию
белых манекенов.

Здесь нет ни одного платного ассета: все анимации ударов, полёта, лазеров и ульты
**процедурные** — их считает клиентский аниматор, который поворачивает шарниры
R6-рига в реальном времени. Эффекты собраны из неоновых деталей, звуки — встроенные
Roblox. Хочешь фирменные анимации из Toolbox — просто вставь ID в конфиг (см. ниже).

---

## Как играть

| Клавиша | Действие |
|---|---|
| **ЛКМ** | Комбо из 5 ударов (можно зажать — серия идёт сама; 5-й удар — вертушка с разворотом на 360°) |
| **ПКМ** (зажать) | Заряженный тяжёлый удар: держи до 1.2 сек — урон 170 → 470 + снос |
| **E** | Пинок с подбросом (в воздухе — «выбивает» противника вверх) |
| **Q** | Рывок сквозь врагов (короткая неуязвимость, след-призраки) |
| **F** | Плазменный лазер в прицел (луч 700 стадов, урон 230) |
| **C** (зажать) | Лазерный залп: шквал выстрелов с двух ладоней |
| **X** | **УЛЬТА «ОБЛИТЕРАЦИЯ»** — когда шкала заряжена на 100% |
| **R** (зажать) | Блок: −75% урона и сильное отталкивание атакующего |
| **V** | Полёт |
| **Пробел** (в воздухе) | Двойной прыжок с сальто |
| **Shift** | Бег на земле · буст в полёте |
| **Пробел / Ctrl** (в полёте) | Вверх / вниз |
| **Z** | Поза силы + энергетический всплеск |
| **T** | Восстановить все манекены |
| **H** | Скрыть/показать панель управления |

### Полёт
Нажми **V** — боец встаёт в позу супермена и летит туда, куда смотрит камера.
Пробел — вверх, Ctrl — вниз, Shift — буст (тратит энергию). В полёте скорость
и манёвренность выше, есть крены в поворотах и трейл за спиной. Если улететь за
арену и упасть ниже −55 стадов — сервер вернёт тебя на спавн.

### Ультa «ОБЛИТЕРАЦИЯ»
Шкала копится за нанесённый и полученный урон плюс понемногу сама.
При 100% бойца обволакивает аура, а по нажатию **X**:
1. зарядка с подбросом в воздух и столбом света;
2. нова-вспышка по всей арене;
3. **14 энергетических снарядов**, летящих в ближайших врагов с уроном по площади;
4. **ГИГАНТСКИЙ ЛУЧ ОБЛИТЕРАЦИИ** — 1500 урона по всему коридору;
5. финальная нова и опалины на полу.

### Манекены
8 белых тренировочных бойцов трёх типов на постах вокруг центра:

| Тип | HP | Размер |
|---|---|---|
| МАНЕКЕН | 1 600 | 1.0× |
| ТЯЖЁЛЫЙ МАНЕКЕН | 7 000 | 1.25× |
| ТИТАН-МАНЕКЕН | 30 000 | 1.75× |

У них есть табличка с полосой HP, вспышка при попадании, рэгдолл при нокауте
и авто-респавн через 2.6 сек. Отброшенный далеко манекен сам возвращается на пост.

## Что внутри арены

* Тёмный неоновый пол 260×260 с светящимся контуром, спицами и укрытиями.
* Центральный боевой пилон с энергосферой и круговым спавном.
* Две боковые платформы с рампами и оградами.
* 12 колонн с вращающимися кольцами (крутятся на клиенте, ноль нагрузки на сеть).
* Арки-ворота, парящие сферы, бездна под ареной.
* **Табло «ЛУЧШИЕ БОЙЦЫ АРЕНЫ»** — урон, нокауты и лучшее комбо в реальном времени.

## HUD

* Полосы **ЗДОРОВЬЕ / ЭНЕРГИЯ / УЛЬТА** (с «догоняющей» полосой урона).
* Панель 12 способностей с откатами и подсветкой нехватки энергии.
* Прицел + маркер попадания (крит — золотой, нокаут — увеличенный).
* Всплывающие цифры урона в мире, криты 2×.
* Счётчик комбо, статистика (урон, DPS за 5 сек, макс. удар, нокауты).
* Баннеры событий, виньетка при низком HP, тряска и вспышки камеры.

## Хочешь свои анимации из Toolbox?

Открой `ReplicatedStorage → CombatConfig`, найди таблицу `Config.ToolboxAnims`
и впиши ID анимации в нужную строку:

```lua
Config.ToolboxAnims = {
    punch1 = "rbxassetid://1234567890",  -- правый клик по анимации → Copy Asset ID
    ...
}
```

Если строка заполнена — для этого действия играет твоя анимация, а процедурная поза
отключается. Пустые строки = всё считается процедурно (как сейчас).

## Тюнинг баланса

Все цифры собраны в **`ReplicatedStorage.CombatConfig`**: урон комбо, откаты,
стоимость энергии, заполнение ульты, скорость полёта, HP бойца и манекенов,
звуки, цвета. Меняешь таблицу — меняется и на сервере, и на клиенте.

## Архитектура

```
ReplicatedStorage
├── CombatConfig      — баланс, цвета, звуки, ID анимаций из Toolbox
├── CombatPose        — процедурные позы R6-рига (+R15 на всякий случай)
├── CombatActions     — 22 анимации: комбо, пинок, лазер, залп, полёт, ульта…
├── CombatAnimator    — клиентский аниматор всех бойцов + локальные эффекты
├── CombatHud         — интерфейс
├── CombatCamera      — тряска, вспышки, виньетка, FOV
├── CombatFloat       — всплывающие цифры урона
├── CombatInput       — управление и клиентская логика
└── CombatRemotes     — Attack, Action, Feedback, Hurt, Knock, Ult, Sfx, Ack

ServerScriptService
├── CombatServer      — авторитетная боёвка, ульта, leaderstats, табло
├── CombatVfx         — серверные эффекты (лучи, новы, взрывы, призраки)
└── CombatDummies     — сборка белых манекенов, рэгдолл, респавн

StarterPlayer
├── StarterCharacter  — R6-боец с энергоядром в груди
└── StarterPlayerScripts/CombatClient — точка входа клиента
```

**Сервер** проверяет откаты, энергию и заряд ульты, наносит урон, раскидывает
бойцов, запускает эффекты и ведёт статистику. **Клиент** только отправляет
намерения (`Attack:FireServer`) и рисует анимации/эффекты.

## Как пересобрать файл

Всё генерируется детерминированно:

```bash
python3 tools/generate_epic_combat.py
```

Исходники Lua лежат в `tools/lua/*.lua` — это обычные текстовые файлы, их удобно
править и линтовать. Генератор просто вшивает их в `.rbxlx`.

## Управление в Studio

* Стартовый персонаж — классический R6 (2×1×1 конечности), рост и хитбокс
  предсказуемы: `HumanoidRootPart` стоит на 3 стада, ступни на 0.
* Полёт включается на клиенте (`PlatformStand = true`), поэтому Humanoид
  не мешает управлению, а сервер видит обычное перемещение владельца.
* Нокдаун: сервер отключает Motor6D и вешает BallSocketConstraint — получается
  рэгдолл, который видит каждый игрок.
* `Workspace.StreamingEnabled = false` — вся арена грузится сразу (так надёжнее
  для боёвки).
