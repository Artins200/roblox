# EPIC COMBAT ARENA 2.0 — боёвка для Roblox Studio

Один файл — готовая боевая арена. Открой **`epic_combat.rbxlx`** в Roblox Studio
(File → Open from File…), нажми **Play (F5)** — и устрой облитерацию белых
манекенов.

Играешь **своим обычным аватаром** (Roblox сам подгружает скин, одежду и лицо).
Анимаций-ассетов нет вообще: все удары, полёт и ульта — **процедурные позы**,
которые клиент считает и накладывает на шарниры в реальном времени. Работает и
на R6, и на R15.

---

## Управление

| Клавиша | Действие |
|---|---|
| **ЛКМ** | КОМБО из 4 ударов: джеб → кросс → апперкот → **вертушка на 360°**. Можно зажать — серия пойдёт сама |
| **F** | ПИНОК-лончер: подбрасывает врага в воздух |
| **R** | ЛАЗЕР: импульс на 800 стадов сквозь всё живое по пути |
| **X** | **УЛЬТА «ОБЛИТЕРАЦИЯ»** — когда шкала заряжена на 100% |
| **V** | ПОЛЁТ (вкл/выкл) |
| **Пробел** (в воздухе) | Двойной прыжок с сальто |
| **Shift** | Бег на земле · ускорение в полёте (тратит энергию) |
| **Пробел / Ctrl** (в полёте) | Вверх / вниз |
| **T** | Вернуть манекены на места |
| **H** | Панель подсказок |
| **F3** | Диагностика (что видит аниматор, сеть, состояние) |

### Комбо (ЛКМ)
Каждый удар — это полноценная анимация: замах в противоположную сторону, резкий
кадр с разворотом бёдер и корпуса, проводка и оседание. На попадании — хит-стоп,
толчок камеры, искры, вспышка и цифра урона. Четвёртый удар — вертушка с
разворотом на 360°, кольцом-разрывом и отбросом.

| Звено | Урон | Особенность |
|---|---|---|
| 1 · джеб | 230 | быстрый, рывок вперёд |
| 2 · кросс | 290 | разворот корпуса |
| 3 · апперкот | 360 | приседание → подброс вверх |
| 4 · вертушка | 640 | 360°, мощный отброс |

### Полёт (V)
Боец вытягивается в позе супермена: руки-крылья отведены назад, ноги вытянуты,
голова поднята. В полёте работают **крены в поворотах** (банк), тангаж по
вертикальной скорости (пикирование/набор высоты), за плечами тянутся две
энергетические ленты-крыла, поза меняется на «буст» при ускорении (Shift).
Скорость 96 → 178 стадов/с на бусте. За полёт и буст тратится энергия.

### Ульта «ОБЛИТЕРАЦИЯ» (X)
Шкала копится за нанесённый урон, полученный урон и понемногу сама. При 100%:
1. зарядка — боец приседает, собирает энергию в руках, вокруг крутятся кольца и столб света;
2. **НОВА** — вспышка на 46 стадов, урон 620 с отбросом и подбросом;
3. **ГИГАНТСКИЙ ЛУЧ** — 1450 урона по всему коридору длиной 220 стадов;
4. приземление — слэм с ударной волной, пылью, опалиной и уроном 320 по площади.

## Манекены

Это **просто обычные белые болванчики** — точь-в-точь классический Dummy: стоят
на своих подиумах по кругу арены, ничего не делают и принимают любые удары.

* восемь штук, белые, R6-риг, лицом к центру;
* жизнь не кончается — можно бить сколько угодно;
* на попадании: вспышка красным, отдача корпусом (наклон по направлению удара),
  искры и цифра урона;
* если сильно отбросить — сами сползаются/возвращаются на место;
* `T` — вернуть всех на места мгновенно.

У них нет имён, полосок HP и никакого ИИ.

## Что внутри арены

* Тёмный неоновый пол 260×260 с контуром, спицами и укрытиями.
* Центральный пилон с энергосферой и спавн-подиум.
* Две боковые платформы с рампами и оградами, 12 колонн с вращающимися кольцами.
* Арки-ворота, парящие сферы, бездна под ареной, прожекторы.
* **Табло «ЛУЧШИЕ БОЙЦЫ АРЕНЫ»** — урон и нокауты в реальном времени.
* Подиумы манекенов (`DummyPads`) — круг радиусом 42 стада.

## Как устроено (для правок)

```
ReplicatedStorage
├── CombatConfig     — ВСЕ настройки: урон, кулдауны, цвета, звуки, анимации Toolbox
├── CombatPose       — процедурные позы: шарниры R6/R15, вращение вокруг родного C0
├── CombatActions    — библиотека анимаций: комбо, пинок, лазер, ульта, полёт, реакции
├── CombatAnimator   — клиентский аниматор: позы, трейлы, аура, звуки, вспышки
├── CombatHud        — интерфейс: 4 кнопки атак внизу по центру, полосы, комбо
├── CombatCamera     — тряска, толчки, вспышки, виньетка, FOV
├── CombatFloat      — всплывающие цифры урона
├── CombatInput      — управление и приём серверных событий
└── CombatRemotes    — Attack · Action · Feedback · Hurt · Ult · Sfx · Ack

ServerScriptService
├── CombatVfx        — все эффекты из неоновых деталей (лучи, новы, искры, пыль)
├── CombatDummies    — белые манекены
└── CombatServer     — урон, энергия, ульта, регенерация, возврат упавших, табло

StarterPlayerScripts
└── CombatClient     — запуск подсистем (каждая в своём pcall)
```

### Перегенерация файла
Арену и все скрипты собирает Python-генератор:

```bash
python3 tools/generate_epic_combat.py     # → epic_combat.rbxlx
```

Исходники Lua лежат в `tools/lua/*.lua` и вшиваются в файл как есть — правь их
и перегенерируй.

### Проверки (без Roblox)
```bash
python3 tools/check_refs.py    # ссылки между модулями, имена анимаций, fx-события, remote'ы
```

## Тонкая настройка

* **Урон и кулдауны** — `Config.Combo.damage`, `Config.Damage.*`, `Config.Abilities`.
* **Скорость/мощь полёта** — `Config.Move.flySpeed`, `flyBoost`, `flyAccel`, `flyVertical`.
* **Ульта** — `Config.Ult` (как копится), `Config.Damage.ult*` (урон).
* **Манекены** — `Config.Dummy`: `count`, `ringRadius`, `color`, `hitPush`.
* **Свои анимации из Toolbox** — впиши ID в `Config.ToolboxAnims`:
  ```lua
  Config.ToolboxAnims = {
      punch1 = "rbxassetid://1234567890",
      kick   = "rbxassetid://...",
      fly    = "rbxassetid://...",
  }
  ```
  Для указанных действий процедурная поза отключится и будет играть трек.

## Если что-то не работает

Открой **View → Output** в Studio. Клиент печатает состояние подсистем:

```
[EPIC COMBAT] интерфейс: ок
[EPIC COMBAT] аниматор: ок
[EPIC COMBAT] управление: ок
```

Если какая-то строка начинается со слова `warn` — в ней написано, что именно
упало. Дополнительно **F3** показывает диагностику прямо на экране: сколько
бойцов видит аниматор, какой риг (R6/R15), сколько шарниров, активное действие,
есть ли связь с сервером.

Каждая подсистема запускается отдельно, поэтому сбой одной не ломает остальные.
