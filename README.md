# Великий мост залива — место для Roblox Studio

Один файл — целый мир. Открой **`bridge_world.rbxlx`** в Roblox Studio — и всё
загрузится: бухта с водой, берега, острова и гигантский вантовый мост,
который **собирается по блокам** (как мост Мапуто-Катембе или мосты через Неву).

## Как открыть

1. Скачай `bridge_world.rbxlx`.
2. Roblox Studio → **File → Open from File…** → выбери файл.
3. Нажми **Play** (F5) — и смотри, как мост строится сам:
   - башни-пилоны вырастают снизу вверх блок за блоком;
   - полотно наращивается консолью от каждой башни в обе стороны;
   - за каждым блоком на место выстреливают ванты;
   - последними зажигаются фонари.
4. У западного входа на мост стоит пульт — подойди и нажми **E**, чтобы
   пересобрать мост ещё раз.

## Что внутри

| Элемент | Описание |
| --- | --- |
| **Мост** | Две H-образные башни высотой ~470 стадов, 96 вант, полотно из 128 блоков-сегментов длиной 3840 стадов |
| **Вода** | Бухта с отражающей водой, бликами, пеной у берегов |
| **Локация** | Берега с холмами, скалами, лесом, домами, маяком, островами и дальними горами |
| **Атмосфера** | Закатный «золотой час»: Atmosphere, Bloom, SunRays |
| **Скрипты** | `BridgeAssembler` — сборка моста по блокам; `Ambience` — лодки, блики, маяк |

## Как пересобрать файл

Файл генерируется скриптом (всё детерминированно):

```bash
python3 tools/generate_bridge_world.py
```

После запуска появится обновлённый `bridge_world.rbxlx`.
