# Build A Boat For Treasure — полная копия в Roblox Studio

Один файл — целая игра. Открой **`build_a_boat.rbxlx`** в Roblox Studio (File → Open from File…), нажми Play (F5) и построй лодку своей мечты от начала до сокровища!

## Как играть

1. Ты появляешься на **зелёном причале (зона строительства)** с сеткой. В стартовом инвентаре 50💰 и бесплатные деревянные блоки.
2. Нажми **H** (или кнопку 🔨 КИЯНКА), чтобы включить режим строительства. Внизу появится панель инвентаря — выбери блок, наведи курсор и нажми **ЛКМ**, чтобы поставить его (блоки ставятся с привязкой к сетке). Блоки автоматически привариваются друг к другу (WeldConstraint).
3. Подойди к **рычагу КРАСНО-ЗОЛОТОГО ЗАПУСКА** у воды и нажми **E** — вода поднимается, шлюз открывается, твоя лодка открепляется и течение несёт её по реке.
4. Впереди 8 секций препятствий и сундуки с золотом. Доберись до **главного золотого сундука в конце** — там 10000💰!
5. В любой момент подойди к продавцу в магазине или нажми **B**, чтобы открыть МАГАЗИН БЛОКОВ и купить новые материалы и механизмы.

## Управление

| Клавиша | Действие |
|---|---|
| **B** | Открыть/закрыть магазин |
| **H** | Вкл/выкл режим строительства (киянка) |
| **E** | Активировать рычаг запуска / диалог с продавцом |
| **ЛКМ** | В режиме строительства — поставить блок |
| **Esc / X** | Закрыть GUI |

## Как пересобрать файл

Файл детерминированно генерируется скриптом:

```bash
python3 tools/generate_build_a_boat.py
```

После запуска появится обновлённый `build_a_boat.rbxlx`, который можно сразу открывать в Roblox Studio.

## Под капотом

- **Сервер** (`ServerScriptService/GameServer`): leaderstats (💰Gold, 📏Distance), стартовый набор блоков, физика запуска (подъём воды, открытие шлюза, открепление лодки, BodyForce для плавучести, постоянный речной поток), выдача награды за сундуки, учёт дистанции.
- **Сервер магазина** (`ShopServer`): RemoteEvent'ы (OpenShop, BuyBlock, PlaceBlock), валидация покупок, спавн блоков в зоне строительства с WeldConstraint к соседям, snap к сетке 4×4.
- **Клиент** (`StarterPlayerScripts/ClientMain`): HUD (золото/дистанция), GUI магазина с сеткой карточек, инвентарь-панель на 10 слотов, киянка с призрачным блоком и snap к сетке.
- **Освещение**: дневное небо, лёгкий туман в глубине реки, Bloom, туман-дымка на горизонте.
